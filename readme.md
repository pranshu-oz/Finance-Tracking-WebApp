# 💰 Personal Finance Tracker

A Spring Boot app to manage your personal finances with ease!

## 🚀 Features

- Track income & expenses
- Categorize transactions
- Dashboard with analytics
- Filter & paginate data
- REST API + Web UI

## 🗂️ Project Structure

- `src/main/java` — Java source code
- `src/main/resources` — Config & static files
- `src/test/java` — Tests

## ⚙️ Tech Stack

- Spring Boot 3
- JPA, Thymeleaf
- MySQL

## 🏁 Getting Started

1. **Build:**  
   `./mvnw clean package`

2. **Run:**  
   `./mvnw spring-boot:run`

3. **Test:**  
   `./mvnw test`
